check a download.

every release lists each installer's sha-256 fingerprint in SHA256SUMS (open it). yours should match exactly.

mac

shasum -a 256 ~/Downloads/DuskBot.dmg

windows (powershell)

Get-FileHash $HOME\Downloads\DuskBot-setup.exe -Algorithm SHA256

linux

sha256sum ~/Downloads/DuskBot-amd64.deb
